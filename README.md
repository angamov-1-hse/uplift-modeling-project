# Uplift-моделирование


> Годовой проект магистерской программы **«Искусственный интеллект»**, НИУ ВШЭ, ФКН, 2026/27.
> Трек: **ML**. Уровень сложности: middle.

## О проекте

Цель проекта — построить модель, которая оценивает **uplift**: насколько изменяется вероятность целевого действия клиента под влиянием некоторого воздействия по сравнению с ситуацией без него.

Воздействием может быть, например, маркетинговая коммуникация (email, push, звонок), персональное предложение или изменение условий продукта. Целевым действием может быть покупка, оформление продукта или отклик на предложение. Конкретная постановка задачи будет определена после выбора данных.

## Данные

**Статус: в процессе поиска**

В приоритете — внутренние данные одного из банков: исторические данные о воздействиях на клиентов (например, маркетинговых кампаниях), включающие факт воздействия, признаки клиента и факт целевого действия. Работа с этими данными требует согласования, поэтому финальный датасет будет определён по итогам переговоров.

Если получить внутренние данные не удастся, план Б — открытые датасеты с корректно проведённым экспериментом.

Требования к данным, независимо от источника:

- корректно выделенная контрольная группа;
- признаки клиента на момент до воздействия;
- факт воздействия и факт отклика;
- отсутствие утечек (признаки не должны содержать информацию из будущего относительно момента кампании).

## Задачи

1. **Сбор и подготовка данных** — получение исторических данных о кампаниях: факт воздействия, признаки клиента, факт отклика.
2. **Разведочный анализ данных (EDA)** — изучение распределений, взаимосвязей, дисбаланса классов и различий между группами.
3. **Дизайн эксперимента** — проверка корректности проведения кампании, сопоставимость контрольной и тестовой групп.
4. **Выбор и реализация методов моделирования:**
   - классические подходы: S-Learner, T-Learner, X-Learner;
   - современные подходы: методы на основе деревьев, в частности Causal Forest.
5. **Оценка качества модели** — специализированные метрики uplift-моделирования.
6. **Интерпретация результатов** — выделение групп с наибольшим предсказанным uplift («убеждаемые») и с отрицательным uplift («не беспокоить»).
7. **Разработка сервиса** — обёртка над обученной моделью для инференса.
