# Uplift-моделирование


> Годовой проект магистерской программы **«Искусственный интеллект»**, НИУ ВШЭ, ФКН, 2026/27.
> Трек: **ML**. Уровень сложности: middle.

## О проекте

Цель проекта — построить модель, которая оценивает **uplift**: насколько изменяется вероятность целевого действия клиента под влиянием маркетинговой коммуникации по сравнению с ситуацией без неё.

Модель должна ранжировать клиентов по ожидаемому дополнительному эффекту коммуникации и выделять по нему сегменты клиентов.

## Данные

Для обучения моделей будем использовать открытый датасет [**X5 Retail Hero**](Открытый датасет **X5 RetailHero**) с данными о клиентах X5 Retail Group и их транзакциях:

- `clients.csv` — общая информация о клиентах;
- `purchases.csv` — история покупок клиентов **до коммуникации**;
- `uplift_train.csv` — обучающая выборка: `treatment_flg` (факт коммуникации),
  `target` (факт покупки после коммуникации);
- `uplift_test.csv` — тестовая выборка для оценки uplift.

Данные загружаются через `sklift.datasets.fetch_x5()`.

Ключевые требования к данным, которые соблюдены:
- корректно выделенная контрольная группа;
- есть факт воздействия в виде коммуникации и факт отклика в виде совершения покупки;
- отсутствие утечек: признаки не содержат информацию из будущего относительно
  момента кампании.

## Задачи

1. **Сбор и подготовка данных** — получение исторических данных о кампаниях: факт воздействия, признаки клиента, факт отклика.
2. **Разведочный анализ данных (EDA)** — изучение распределений, взаимосвязей, дисбаланса классов и различий между группами.
3. **Дизайн эксперимента** — проверка корректности проведения кампании, сопоставимость контрольной и тестовой групп.
4. **Выбор и реализация методов моделирования:**
   - классические подходы: S-Learner, T-Learner, X-Learner;
   - современные подходы: методы на основе деревьев, в частности Causal Forest.
5. **Оценка качества модели** — специализированные метрики uplift-моделирования.
6. **Интерпретация результатов** — выделение групп с наибольшим предсказанным uplift («убеждаемые») и с отрицательным uplift («не беспокоить»).
7. **Разработка сервиса** — обёртка над обученной моделью для инференса.
